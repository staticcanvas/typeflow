# TypeFlow

> {{ site.Params.description }}

TypeFlow is published as `@staticcanvas/typeflow`. It provides interruptible typewriter animations, directional reveal and erase modes, safe HTML rendering, smart text morphing, token streaming, sequence orchestration, framework adapters, and optional telemetry, debugging, audio, keystroke, and extended-character modules.
