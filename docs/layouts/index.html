Engine features

Read the API reference

Multi-Directional & Erase Modes

Type left-to-right, right-to-left, or expand from center. Erase via backspace (end), left erosion (start), inward shrink (center), opacity cross-fades (fade), or instant resets.

Erase styles guide →

Scramble & Charset Presets

Scramble characters using nine built-in character sets: Matrix, Blocks, ASCII, Extended, Binary, Hex, Braille, Runic, and Cyber.

Charset guide →

Procedural Web Audio

Generate typing sounds with the browser Web Audio API. No audio files are required.

Audio documentation →

Text morphing

Computes longest common prefixes between active DOM text and new content, automatically backspacing only the mismatched characters without full teardowns.

Morph API →

Text streaming

Queue incoming text chunks and type them in order.

Stream ingestion →

Safe HTML & Sanitization

Type HTML while preserving allowed tags and attributes. The sanitizer removes elements and attributes outside the allowlist.

Sanitization guide →
