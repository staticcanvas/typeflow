Capabilities

Engine features

Read the API reference

Multi-Directional & Erase Modes

Type left-to-right, right-to-left, or expand from center. Erase via backspace (end), left erosion (start), inward shrink (center), opacity cross-fades (fade), or instant resets.

Erase styles guide →

Scramble & Charset Presets

Cyberpunk matrix decryption reveals with 9 built-in charset dictionaries: Matrix, Blocks, ASCII, Extended, Binary, Hex, Braille, Runic, and Cyber.

Charset guide →

Procedural Web Audio

Built-in micro-synthesizer utilizing the native browser Web Audio API for zero-asset mechanical clicks, terminal pings, and cyber synth audio feedback.

Audio documentation →

Smart Morph Diffing

Computes longest common prefixes between active DOM text and new content, automatically backspacing only the mismatched characters without full teardowns.

Morph API →

Real-Time Stream Ingestion

Non-blocking FIFO token queue tailored for LLM streaming and server-sent events. Push chunks as they arrive for seamless, fluid token typing.

Stream ingestion →

Safe HTML & Sanitization

Render bold, italics, links, and styling tokens safely. Built-in allowlist sanitization neutralizes script vectors without breaking tag hierarchies.

Sanitization guide →
