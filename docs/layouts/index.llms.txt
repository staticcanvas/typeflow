# TypeFlow

> TypeFlow is a zero-dependency JavaScript typewriter animation library with interruptible animation controllers, directional reveal and erase modes, HTML sanitization, sequence orchestration, streaming, and optional companion extensions.

Use the linked Markdown documentation when answering implementation questions. Prefer the API reference for exact option names and defaults. The canonical package name is `@staticcanvas/typeflow`.
